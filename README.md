# Online Retail Sales Performance Analysis


## Project Overview

This project analyzes online retail transaction data to identify sales performance, product performance, customer behavior, and business insights.


## Business Problem

An online retail company wants to evaluate historical transaction data to understand revenue trends, best-selling products, customer purchasing patterns, and market distribution.


## Objectives

The objectives of this project are:

- Analyze overall sales performance
- Identify top-performing products
- Analyze customer purchasing behavior
- Identify sales trends over time
- Provide business recommendations based on data


## Dataset

Dataset:
Online Retail Dataset

Source:
UCI Machine Learning Repository

Period:
December 2010 - December 2011
