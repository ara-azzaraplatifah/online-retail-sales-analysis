# Online Retail Sales Performance Analysis


## Project Overview

This project analyzes online retail transaction data to understand sales performance, customer behavior, and product performance.


## Business Problem

An online retail company wants to evaluate historical sales data to identify important business insights such as revenue trends, best-selling products, and customer purchasing patterns.


## Objective

The objectives of this project are:

- Analyze overall sales performance
- Identify top-performing products
- Understand customer purchasing behavior
- Analyze sales distribution by country
- Create business recommendations based on data


## Dataset

Dataset Name:
Online Retail Dataset

Source:
UCI Machine Learning Repository

Period:
December 2010 - December 2011
